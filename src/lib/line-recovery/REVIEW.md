# One-time LINE API menu recovery — preparation only

The account owner has approved creation of the specified global API default for `@930xzcyi`. This endpoint is designed for one attempt only when the API menu list is empty and the API default is absent. The fixed menu and JPEG come from the local recovery manifest; the expected JPEG SHA-256 is checked locally and on LINE before and after assignment. Production readiness and verification are still required before execution.

The API default takes precedence over the native LINE OA Manager menu (including the unverified menu 20269826); individual user assignments retain higher priority. LINE has no compare-and-set on a default: another operator can change the state between the final read and assignment. A successful API check does not prove mobile display.

A permanent Firestore marker in `server_line_recovery_once/restore_930xzcyi_v1` is atomically created before any provider write. It is deliberately never expired, reclaimed or reset by this code. A timeout, crash or failure after any write can leave a partially created menu, and repeating the attempt may create duplicates. Investigate LINE and the marker manually; do not retry, delete, or reset the marker automatically.

Before any proposed deployment, verify the production Firestore identity and named database have permission to create and update the private marker, the browser cannot access it, and the built server function includes the JPEG. This has not been verified against production. Unavailable persistence blocks all provider writes. Deleting the route from a new deployment does not disable older immutable deployment URLs. Every accessible deployment that contains this route must use the same protected database and permanent marker, or its deployment must be revoked or disabled. Maintain the shared marker even after removing the route from a new deployment. The target production site's staff authentication and exact account must also be verified. These checks do not imply authorization to mutate LINE.
